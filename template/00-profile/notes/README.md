# Сырьё для банков

Сюда попадает всё, из чего потом делаются факты, истории, ответы и сильные стороны:

- **dump** — надиктованное или вставленное: CRM → «Наполнение» → «Сбросить сырьё», старое резюме,
  заметки после созвона, выгрузка из LinkedIn;
- **session** — лог сессии наполнения с Claude (`/fill`): вопрос Claude и твой ответ, почти дословно.

Файл: `<дата>-<тема>.md`, в шапке `status: new | processed`. Пока `new`, он стоит первым в очереди
наполнения. Факты и истории ссылаются сюда в `source` — так любую цифру можно проследить до твоих слов.

Сырьё не нужно причёсывать: надиктуй как есть, с повторами. Разобранный файл не удаляй — на него
ссылаются факты.
